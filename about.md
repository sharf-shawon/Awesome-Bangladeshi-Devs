# About

Awesome Bangladeshi Developers is a curated and automated community directory for discovering Bangladeshi open-source contributors and projects.

## What this site offers

- Live developer search, sorting, and filtering
- Project discovery with repository-level metadata
- Visual dashboards for languages, locations, and activity trends
- Dedicated profile pages for each listed developer

## Data quality

- Manual submissions are stored in `data/users.json`
- Automated/statistical entries are stored in `data/automated.json`
- Validation pipelines keep all published data consistent and schema-safe

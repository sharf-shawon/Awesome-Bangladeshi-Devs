# Contributing to Awesome Bangladeshi Devs

We love contributions! Here's how you can help:

## Adding Yourself or Someone Else

The easiest way to add a developer to this list is to open an issue using the [Add Developer](https://github.com/sharf-shawon/Awesome-Bangladeshi-Devs/issues/new?template=add_developer.yml) template.

### Eligibility Criteria
- The developer MUST be from Bangladesh or have strong ties to the Bangladeshi developer community.
- Their GitHub profile MUST be public.

## Technical Contributions

If you'd like to improve the code, site, or scripts:
1. Fork the repo.
2. Create a feature branch.
3. Make your changes.
4. Open a Pull Request.

### Development Setup
- Python 3.12+
- Node.js 20+
- Run `pip install -r requirements.txt`
- Run `npm install`
- Build the site with `npm run build`
